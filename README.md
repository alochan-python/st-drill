# ST午後Ⅱ 高速骨子演習

ITストラテジスト午後Ⅱ（論文）の試験直前用・高速骨子演習Webアプリです。
外部ライブラリなし、ビルド不要の静的サイト（`index.html` をブラウザで開くだけで動きます）。

## モード
- **A 型判定**：過去問（2015〜2019・2021〜2025の28問）に対して 元論文／ITEC／TAC／選ばない を選ぶ
- **B キー再現**：元論文・ITEC・TAC の設問ア／イ／ウの起動キーを答える。入力に無かったキーを赤枠で表示
- **C 骨子展開**：使用型・設問ア〜ウの骨子・変更点を入力（15分タイマーつき）
- **D 本文起動**：骨子ブロックから本文を2〜4文で書く
- **E △×だけ復習**：このセッションで△・×を付けた問題だけを出題し直す。○を付けると対象から外れる

速度ゲージ（1じっくり〜4超高速）は答え合わせで表示する量を切り替えます。入力欄の外ではキーボードの1〜4でも切り替えられます。
採点は自己採点（○△×）です。再現度は B・D の自己採点を型ごとに平均した値（○＝1、△＝0.5、×＝0）です。
速度と記録は localStorage に保存し、「セッションをリセット」で消去できます。

## データ
`data.js` は `docs/` の資料から原文のまま自動で抜き出したものです。資料を直したら作り直してください。

```
node tools/build-data.mjs
```

実行すると件数チェック（05の過去問数、02/03の節数）が表示されます。
D モードで元論文のどの文を正解例にするかの対応は `tools/build-data.mjs` の `MAP` に書いてあります。
