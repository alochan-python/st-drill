# **4. 本番で迷わないための「10秒判定」**

> **① 題名を見る** 基幹／刷新／DX企画／改修要望／真因／再構築／ステークホルダ調整 → 元論文候補。
>
> **② 設問イを見る** 分析・方針・PoC・優先順位・調整なら強い。顧客・収益モデル・新商品が主役なら弱い。
>
> **③ 設問ウを見る** 交渉・経営説明・評価・改善ならU1/U2/U3がそのまま使える。
>
> **④ 骨子を8ブロック以内で置く** A1/A2 → I1/I2/I3/I4 → U1/U2/U3から必要なものだけ選ぶ。全部入れない。
>
> **⑤ 見出しを設問語に合わせる** 『刷新方針』と聞かれたら刷新方針、『DX企画』ならDX企画、『対応方針』なら対応方針と書く。
